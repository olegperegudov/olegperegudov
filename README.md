## Hey, I'm Oleg

I build small tools that solve real problems — usually for myself first, then share them if they turn out useful.

### My projects

**[Ribbit](https://github.com/olegperegudov/ribbit)** — Voice-to-text dictation for Windows. Hold a hotkey, speak, release — text appears in any app. Free, private, lightweight. Built with Tauri + Rust.

**[Snatch](https://github.com/olegperegudov/snatch)** — Video stream downloader. Chrome extension + local daemon that catches HLS/DASH streams and downloads them as mp4. One click, works in the background.
